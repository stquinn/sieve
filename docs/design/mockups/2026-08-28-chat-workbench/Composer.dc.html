A″ — The composer

The full document-editor lens mounted on an in-memory draft container. Pointer-first: a question is mostly utterance + references; authored blocks are fragments, not works.
1
Draft surfaceLENS
A real editor lens (PM), not a textarea — same surface, same paste pipeline, same block minting as any note. The chat host claims Enter = send pre-coreHOST; every other key falls through to the editor. Focus ring is the standard orange.
2
Mention typeaheadHOST
MentionService — a tenant of the workspace wire (mention-query/mention-result). Accepting inserts the @Title token in prose AND the chip below: one gesture, an rel: attach reference element under the hood.
3
Seeded quoteLENS
The ❝ read-control on any record quotes it into the composer as a pinned reference element — purple, frozen at the cited version. A follow-up is a quote plus more words.
4
Pasted fragmentLENS
Paste mints a whole block through the registry’s paste-match — the open seam. Inside the draft it keeps its full chrome and is editable; the border is the code kind’s own.
5
Chip row (draft state)LENS
Attach chips are removable here (×) — the one place a chip mutates, because the draft is not yet a record.
6
SendHOST
Send = append exchange on the DOCUMENT wire (create ai-block + submit job). The draft’s block list becomes the question list verbatim. No Ask/Explain menu items inside the composer — you are already inside one; the host-scoped context menu omits them.
