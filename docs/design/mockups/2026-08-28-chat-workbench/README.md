# Chat & Workbench design mockups (2026-08-28)

Frozen picture of record for the chat lens (#102) and the email/code workbench designs.
Each `.dc.html` opens standalone in a browser — inline styles, no build, no network
needed (the Google Fonts link degrades to the fallback stack). Yellow pins + the
right-hand rails annotate HOST/LENS ownership per interactive region.

Normative companion: `docs/design/specs/2026-08-28-chat-lens-design.md` — including the
precedence rules (spec wins on behaviour; these files win on layout; NEITHER wins on
colour values — implementations use `--theme-*` tokens, never the resolved Mariana hex
these files carry for portability).
