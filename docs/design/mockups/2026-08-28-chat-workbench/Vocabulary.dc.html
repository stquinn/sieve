Live block vs record

One renderer per kind, one flag. A record keeps the full anatomy and every read affordance; only mutation leaves. Nothing else may differ — that is what makes the two surfaces read as one system.

Gesture routing on a record
Elements are anonymous (no block identity in the DOM), so every right-click resolves upward to the parent exchange — the host menu speaks about the record, never about its internals. Read affordances (copy, expand, fold, scroll) stay live all the way down.
