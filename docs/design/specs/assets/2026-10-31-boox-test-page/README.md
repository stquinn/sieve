# Boox Note Air 2 test page, 2026-10-31 (spike A of #205, epic #204)

The first fixture of the kind §5.5 of the live-ink design describes: a real page as SieveInk
exports it, beside the bitmap the tablet itself drew.

| File | What |
|---|---|
| `boox-page-strokes.json` | 74 strokes, 17,044 points: pen handwriting and pencil writing plus a shaded square. Per point: x, y (page units, width = 1), pressure (0..1 of 4095), tMillis, tiltX, tiltY (degrees), size. |
| `boox-tablet-render.png` | 1404×1693, what the Onyx engines (fountain for pen, charcoal V2 for pencil) drew for that page. The look-and-feel reference for the Sieve lens. |
| `crude-render-from-points.png` | A 40-line throwaway render of the JSON (`crude-render.py`: width from pressure only, no tilt, no grain). Handwriting matches the tablet at a glance; pencil shading does not — tilt-driven width, grey tone and grain are what the lens has to add. |
| `crude-render.py` | The throwaway. Run with `python3 -I crude-render.py boox-page-strokes.json out.svg`, then `rsvg-convert`. |
| `perfect-freehand-render.mjs` | The second recreation (2026-11-02, the renderer question of #205): perfect-freehand 1.2.3 for the outline of every stroke. **Pen** = one outline per stroke from the real pressure (size 1.35× nominal, thinning 0.75), black. **Pencil (charcoal)** = 10-point chunks, solid black; width from tilt (1.2× nominal × (1+0.9·t²) × (1.1−0.4p), t = (tilt−15)/10 clamped at 0); tone is dot DENSITY, not opacity: each chunk's darkness (0.10 + 0.95·p^1.3) picks one of seven bands and each band is an SVG filter that thresholds one shared feTurbulence so it keeps a measured fraction of dots (12% … 96%; the threshold table was calibrated by rendering a filtered square and counting coverage). Speckle scale baseFrequency 0.7 (~2.5 px at 1404 wide): at 1.1 the noise lattice aliases into visible pixel rows and columns, so keep it well below 1 and re-check in WebKit, which rasterises filters differently from rsvg. Run with `npm i perfect-freehand` beside it, then `node perfect-freehand-render.mjs boox-page-strokes.json out.svg [baseFrequency] [gain] [tilt|narrow]`; the narrow pencil width (no tilt term) is what matched the second fixture, see `../2026-11-02-live-page/`. |
| `perfect-freehand-render.png` | Its output rasterised. Judged by eye against the tablet (2026-11-02): pen "a very good match"; pencil reads as charcoal — writing near-black with grain, hatching as speckled lines, shading darkening by density. Eight variants were tried on the way: smooth polygons with alpha opacity read too thin and textureless, blurred/wide ones as "a smudge", opaque-grey darken blends as marker. The tablet's heavy block is still a little lighter and softer-edged than ours; its pencil writing a touch bolder. |
