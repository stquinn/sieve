§8 — Structural document map (NOT a text minimap)

Design 2026-06-11
Decision: A — the structural map (NOT a text minimap). Flavour-coloured cells, off-screen dirty-glow, viewport box, click-to-jump. The macro zoom of the lineage system. Stage-3 feature.

A document map — but structural, not a minimap

The macro end of the lineage system: not shrunk text, but one cell per block, coloured by flavour, glowing when stale, with faint lineage edges and a viewport marker. It's how "a render five screens away went stale" becomes visible without scrolling. Below: the structural version (A) vs. the classic text minimap you dislike (B).

A

Structural map — flavour cells + staleness + lineage

One cell per block, coloured by flavour, column-rows shown side-by-side, dirty blocks glow amber even when off-screen, faint edge ties a source to its consumers, viewport box shows where you are. Click a cell to jump. Semantic, not decorative.
