Zero external assets — proves the gutter/code-area box chrome is style-complete from :root vars alone.

DiagramRenderer — render mode

Needs mermaid's vendored runtime at the ABSOLUTE path /static/vendor/mermaid.min.js (the real app's Go-embed serves frontend/src/static/ at /static/ — see DiagramRenderer.ensureMermaid()). A plain python3 -m http.server 8642 from the repo root (this file's own top-of-file instructions) can't reproduce that mount, so mermaid 404s here and the renderer falls back to its OWN error box — which is itself a valid bare-page render (the error state is theme-var styled too, just not the success path). To see the real SVG, symlink the vendor dir under this harness's own folder once — ln -s ../../../src/static/vendor frontend/test/harness/static-vendor-check — is more trouble than it's worth for a manual check; simplest is to validate the actual mermaid render path via the live Wails app instead (it serves /static/ for real) and treat this harness's render-mode box as a DOM/CSS-only smoke check.
